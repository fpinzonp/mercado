# Mercado — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PWA para iPhone que sirve de lista de mercado y comparador de precios entre varios mercados, leyendo el nombre real del producto desde una foto.

**Architecture:** App estática (Vite + JS sin framework) publicada en GitHub Pages. Toda la lógica de negocio vive en módulos puros (`src/logica/`) probados con Vitest; los datos se guardan en IndexedDB (`src/datos/`); la lectura de fotos pasa por Gemini y cae a Tesseract.js (`src/ia/`); las vistas (`src/ui/`) son funciones que pintan el DOM a partir del estado y llaman a la capa de datos.

**Tech Stack:** Node 24, Vite 6, Vitest + jsdom + fake-indexeddb, `idb` (envoltorio de IndexedDB), `tesseract.js` v5, `vite-plugin-pwa` (Workbox), GitHub Actions → GitHub Pages.

**Spec:** [docs/superpowers/specs/2026-11-24-mercado-design.md](../specs/2026-11-24-mercado-design.md)

## Global Constraints

- Toda la interfaz en español; dinero en COP, entero, formato `$4.500` (punto de miles, sin decimales).
- Precio unitario con 2 decimales y coma: `$4,50/g`, `$3,20/ml`, `$450,00/un`.
- Unidades internas: `g`, `ml`, `unidad`. Se acepta escribir `kg` y `L`, se convierte al guardar (×1000).
- Fotos: JPEG con lado mayor 800 px.
- Dispositivo objetivo: iPhone con Safari, instalada en pantalla de inicio. Usable a 375 px de ancho con una mano.
- Lista, tachado, comparación y escribir precios a mano funcionan sin internet. Tesseract sin internet es de mejor esfuerzo.
- Gratis: sin servidor; la clave de Gemini la pega el usuario en Ajustes y solo vive en IndexedDB del teléfono.
- Descuento sin `descuentoHasta` es vigente solo el día de `actualizado`. Recordatorio de respaldo a los 14 días.
- Fechas siempre como `YYYY-MM-DD` en hora local del teléfono (nunca `toISOString()` para la fecha del día).

## Review Focus

1. **Precios escritos a la colombiana** ("4.500", "4500", "$ 4.500", "12.990,00"): deben dar 4500 / 12990, nunca 4.5. → test en Task 1.
2. **Tamaño o cantidad en 0, vacíos o no numéricos:** el formulario los rechaza y los cálculos devuelven `null` en vez de `Infinity`/`NaN`. → tests en Tasks 1 y 2.
3. **Unidad incompatible** (Gemini dice "1 L" para un producto en gramos): no se convierte en silencio; el campo de tamaño queda vacío para que lo escriba el usuario. → test en Task 3.
4. **Descuento que vence hoy** ("válido hasta 30/11" el 30/11 a las 23:00 en Bogotá): sigue vigente todo ese día local. → test en Task 2.
5. **Gemini responde algo raro** (JSON dentro de ```json, campos faltantes, texto libre, HTTP 400 por clave mala): se pasa a Tesseract y la clave mala se informa sin bloquear. → test en Task 4.

### Task 2: Motor de comparación y descuentos

**Files:** Create `src/logica/comparar.js`, `src/logica/ofertas.js`, `tests/logica/comparar.test.js`, `tests/logica/ofertas.test.js`

**Interfaces — Consumes:** nada de lógica previa salvo fechas como strings.
**Produces** (tipos de datos que usa todo el proyecto):

```js
// Oferta: { id, productoId, mercadoId, nombreReal, tamano, precioNormal, fotoId?, actualizado,
//           precioDescuento?, detalleDescuento?, descuentoHasta? }
// Item:   { id, productoId, cantidad, tachado, compradoEn? }
```

- `descuentoVigente(oferta, hoy): boolean` — hay `precioDescuento` y `hoy <= (descuentoHasta ?? actualizado)`
- `precioEfectivo(oferta, hoy): { precio, conDescuento }`
- `costoItem(cantidad, oferta, hoy): { paquetes, costo, costoNormal, unitario, conDescuento } | null` — `null` si cantidad o tamaño ≤ 0; `unitario = precio / tamano`
- `compararItem(item, ofertas: Oferta[], hoy): { filas: Array<{ oferta, ...costoItem, esMasBaratoHoy, esMasBaratoNormal }>, soloPorDescuento: boolean }` — filas ordenadas por costo; los empates quedan todos marcados; `soloPorDescuento` = ningún más barato de hoy es también el más barato a precio normal
- `totalesPorMercado(items, ofertasPorProducto: Map<productoId, Oferta[]>, mercados, hoy): Array<{ mercadoId, total, faltan }>` — ordenado por `faltan` asc, luego `total` asc; los ítems tachados también cuentan (es el costo de la lista)
- `totalCombinado(items, ofertasPorProducto, hoy): { total, sinPrecio }` y en el mismo objeto `ahorro` = total del primer mercado de `totalesPorMercado` con `faltan === 0` − `total` (o `null` si ningún mercado está completo)
- `repartirCompra(items, ofertasPorProducto, mercadoId, hoy): { aqui: Item[], otros: Array<{ item, mercadoId, diferencia }> }` — solo ítems sin tachar; `aqui` = el mercado es uno de los más baratos hoy o ningún otro mercado tiene precio; `diferencia` = costo aquí − costo en el más barato (o `null` si aquí no hay precio)
- `fusionarOferta(anterior: Oferta | undefined, nueva: Partial<Oferta>, hoy): Oferta` — si cambia `precioNormal` y la nueva no trae descuento, se conserva el descuento anterior solo si sigue vigente; `actualizado = hoy`

### Task 4: Lectura de etiqueta (Gemini → Tesseract → manual)

**Files:** Create `src/ia/gemini.js`, `src/ia/ocr.js`, `src/ia/leer.js`, `src/img/reducir.js`, `tests/ia/gemini.test.js`, `tests/ia/leer.test.js`

**Interfaces — Consumes:** `detectarTamano` (Task 3). **Produces:**
- `class ErrorIA extends Error { codigo: 'sin_clave'|'sin_red'|'limite'|'clave_invalida'|'respuesta_invalida' }`
- `leerEtiquetaGemini(blob, { clave, modelo, fetchImpl = fetch }): Promise<{ nombre, tamano, unidad }>` — POST a `https://generativelanguage.googleapis.com/v1beta/models/${modelo}:generateContent?key=${clave}` con la imagen en `inlineData` (base64 JPEG), `generationConfig.responseMimeType = 'application/json'`. Prompt: pedir solo JSON `{"nombre": marca + producto sin el tamaño, "tamano": número, "unidad": "g"|"kg"|"ml"|"L"|"unidad"}`, en español, `null` si no se ve. Mapeo: sin clave → `sin_clave`; `fetch` lanza → `sin_red`; 429 → `limite`; 400/403 → `clave_invalida`; JSON que no se puede leer o sin `nombre` → `respuesta_invalida`.
- `parseRespuestaGemini(cuerpo): { nombre, tamano, unidad }` — toma `candidates[0].content.parts[0].text`, quita cercas ```` ```json ````, `JSON.parse`.
- `leerTextoLocal(blob): Promise<{ texto: string, palabras: string[] }>` — `tesseract.js` con `workerPath`, `corePath`, `langPath` apuntando a `import.meta.env.BASE_URL + 'tesseract/'`, idioma `spa`; palabras de 2+ caracteres, sin repetir.
- `leerProducto(blob, { clave, modelo }, deps = { gemini: leerEtiquetaGemini, ocr: leerTextoLocal }): Promise<{ fuente: 'gemini'|'ocr'|'manual', nombre?, tamano?, unidad?, palabras?, aviso?: string }>` — Gemini primero; con cualquier `ErrorIA` pasa a OCR (con `aviso` en español si fue `clave_invalida` o `limite`); si OCR falla → `{ fuente:'manual' }`. En OCR, `tamano/unidad` salen de `detectarTamano(texto)`.
- `reducirImagen(file: File, ladoMax = 800): Promise<Blob>` — `createImageBitmap` + canvas, JPEG calidad 0.8. Sin test automatizado (depende del navegador); se verifica en Task 7.

### Task 9: Agregar precio (foto → lectura → formulario)
